# Terminal Workspace 0.10.0 prerelease

Check the [release page](https://github.com/brant92good/terminal-workspace/releases/tag/v0.10.0)
for download availability and [verification](https://github.com/brant92good/terminal-workspace/blob/v0.10.0/docs/verification.md)
for the recorded source, bundle and public-download checks.

The SFTP menu and optional workspace tab now open the SSH Sessions Files chooser.
Choose a server or saved path before connecting. With both optional companions
enabled, the workspace opens Remote, Local Herdr, Ports, then SFTP and keeps
Remote selected. Ordinary new tabs still open SSH Sessions.

This version bundles Ports 0.9.1, SSH Sessions 0.8.0 and SSH Files 0.3.0
beta. Ports brings grouped Name-first rows, buffered output, Open automatically
in the edit form, and explicit HTML-title preview. The file browser includes
the qualified controls described in its own release; native Explorer drag/drop
is not part of this bundle.

The package requires all five leaf license/notice files and preserves their
released bytes. Its installer verifies all 26 named payloads before replacement;
SourceCheckout installs 13 generated runtime/build/notice files while retaining
source, configuration and preferences. Existing automatic-forward choices are
not enabled by installation.

The Windows integration remains Windows-only. Files, macOS leaf support and
taskbar grouping retain their beta limits. These source and package checks do
not qualify physical pin clicks or desktop return-shortcut latency.
